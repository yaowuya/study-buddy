# 作业陪伴助手 — 产品需求文档

> 来源：Stitch 设计稿（projects/1261262470017047406）
> 整理日期：2026-05-10

## 1. 产品背景与目标

解决"双职工"家庭中，家长下班晚导致孩子遗忘作业、无法独立完成听写、作业进度不可控的痛点。

通过"家长远程布置 → 云端同步 → 孩子本地执行 → 智能语音听写"的业务链路，实现高效的家庭教育协作与监督。

## 2. 用户角色

| 角色 | 描述 | 主要端 |
|------|------|--------|
| 家长 | 任务发起者与验收者。录入待办、配置听写、批改作业 | PC Web + 手机端 |
| 学生 | 任务执行者。接收待办、跟随语音听写、提交作业 | 平板 + 手机端 |

## 3. 核心功能模块

### 3.1 账号与家庭绑定

- 家长注册后生成唯一"家庭连接码"
- 学生端扫码或输入连接码完成角色绑定
- 一个家庭账号支持一个家长、一个学生设备

### 3.2 家长端功能

#### 3.2.1 任务管理

| 功能 | 详细说明 |
|------|----------|
| 任务发布 | 支持"学校任务"与"家庭任务"两种类型；要素：标题、描述、预计耗时 |
| 听写配置 | 录入听写词组或段落；支持批量粘贴后自动拆分词组；支持设置语速和词语间停顿间隔 |
| 任务追踪 | 列表或日历视图展示任务分布；实时查看孩子进度（未开始 / 进行中 / 待批改）|

#### 3.2.2 作业验收

| 功能 | 详细说明 |
|------|----------|
| 线上批改 | 查看任务完成状态；支持对任务标记"对/错"及填写简单评语 |
| 错题本管理 | 自动收集被标记为"错"的任务；按学科（语文/数学/英语）归类统计；支持错题归档 |

### 3.3 学生端功能

#### 3.3.1 待办中心

| 功能 | 详细说明 |
|------|----------|
| 今日任务看板 | 大卡片、大字体展示当日全部任务；区分学校任务与家庭任务 |
| 状态流转 | 点击改变任务状态：待开始 → 进行中 → 提交/完成 |

#### 3.3.2 听写模式

| 功能 | 详细说明 |
|------|----------|
| 智能语音听写 | 将家长配置的文字通过设备本地 TTS 转为语音播放 |
| 播放控制 | 暂停、重新播放当前词、手动切换下一个词 |
| 语速设置 | 读取家长配置的语速和停顿间隔 |

#### 3.3.3 作业提交

| 功能 | 详细说明 |
|------|----------|
| 快捷完结 | 点击"完成"即可提交任务，状态变为"待批改" |

#### 3.3.4 激励反馈

- 完成当日所有任务后，弹出全屏勋章/鼓励动画给予正向反馈

### 3.4 数据管理

| 功能 | 详细说明 |
|------|----------|
| 多端同步 | 客户端定时轮询（30秒间隔）获取最新任务状态 |
| 离线支持 | 无网络时可查看已缓存的当日任务并本地操作，网络恢复后自动同步 |
| 数据导出 | 历史任务和错题数据支持以文件形式导出；支持重新导入恢复 |

## 4. 核心业务流程

```
发布阶段：家长登录 → 创建今日任务（待办/听写）→ 保存同步至云端
执行阶段：学生打开应用 → 自动轮询获取任务 → 逐项点击执行
听写阶段：学生点击听写任务 → 设备 TTS 报词 → 学生纸上书写
提交阶段：学生点击完成 → 状态变为"待批改"
验收阶段：家长查看完成状态 → 标记对/错 → 错题自动入错题本
```

## 6. 设计规范摘要

- **主色**：Sky Blue `#005DA7` / `#4F46E5`（两套设计系统）
- **辅色**：Soft Yellow（成就高亮）、Mint Green（成功/进度）
- **字体**：Lexend（专为降低阅读疲劳设计，适合儿童）
- **圆角**：`rounded-xl`（1.5rem）大容器，`rounded-lg`（1rem）卡片
- **触控目标**：最小 48×48px（适配儿童手指）
- **间距基准**：8px grid
- **风格**：Playful Clarity — 活泼但不凌乱，大字体大卡片

## 7. 非功能需求

| 项目 | 要求 |
|------|------|
| 平台 | iOS + Android（UniApp 编译）；家长端兼容 H5 |
| 响应时间 | 任务列表加载 < 2s |
| 离线 | 学生端支持断网查看当日任务缓存 |
| 安全 | JWT 认证，接口需鉴权 |
