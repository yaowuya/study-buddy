# 周期作业计划 PRD

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 功能名称 | 周期作业计划 |
| 产品 | 作业陪伴助手（Study Buddy） |
| 目标角色 | 家长、学生 |
| 状态 | 已确认 |
| 交互原型 | [prototype.html](prototype.html) |
| PRD 形态 | 单文件 |

## 2. 背景与问题

家长目前只能为某一个日期创建一份作业。当同一项作业需要连续执行一周、一个月或一段自定义时间时，家长必须每天重复布置，操作成本高，也容易漏布置。

本功能允许家长一次创建一个有明确日期范围的作业计划。计划有效期内，系统按日期生成独立作业；学生或家长打开作业页面时，系统补齐截至当天尚未生成的作业。家长可在作业页面查看和管理仍在执行的计划。

同时，现有布置页面虽然默认关闭听写，但关闭后仍展示被禁用的输入区域和说明。本功能将听写改为条件展示，减少非听写作业的页面干扰。

## 3. 产品目标

1. 家长可以一次布置一段时间内每天重复执行的作业。
2. 系统可靠、幂等地为计划中的每个日期生成一份独立作业。
3. 即使某天无人打开应用，之后打开时也不会遗漏该日期的作业。
4. 家长可以查看、完整编辑或删除尚未过期的计划。
5. 已生成作业保持稳定，不因计划后续编辑或删除发生变化。
6. 听写配置仅在家长明确开启时出现。

## 4. 非目标

本期不包含：

- 作业提醒、推送通知或日历提醒；
- 跳过周末、法定节假日或指定星期；
- 每周、隔日等复杂重复规则；
- 单独的过期计划或已删除计划管理页面；
- 修改计划后同步更新已生成作业；
- 删除计划时级联删除已生成作业；
- 独立操作审计日志；
- 计划暂停和恢复；
- 学生编辑或删除作业计划。

## 5. 用户故事

### 5.1 家长创建今日作业

作为家长，我希望时间计划默认选择“今日作业”，从而可以沿用原有的一次性布置流程，不需要额外操作。

### 5.2 家长创建周期计划

作为家长，我希望选择最近一周、最近一个月或自定义日期范围，一次设置每天需要完成的作业内容。

### 5.3 家长查看活动计划

作为家长，我希望在“作业”页面底部查看仍在执行的计划、生成进度及作业内容，以便掌握计划运行状态。

### 5.4 家长编辑计划

作为家长，我希望完整修改计划的日期、科目、标题、听写内容、作业要求和预计时长，同时不影响已经生成的作业。

### 5.5 家长删除计划

作为家长，我希望停止一个计划继续生成新作业，同时保留此前已经生成、进行中、已提交或已批改的作业。

### 5.6 学生接收每日作业

作为学生，我希望打开作业页面时看到计划为各日期生成的独立作业，包括此前遗漏生成的作业。

## 6. 核心概念

### 6.1 今日作业

某一个日期下可独立完成、提交和批改的作业实体。今日作业也可以由家长直接创建，不一定来自计划。

### 6.2 作业计划

家长创建的作业模板，包含有效日期范围和生成每日作业所需的全部内容。计划本身不可提交或批改。

### 6.3 计划生成实例

系统根据作业计划和目标日期生成的独立作业。生成后即成为快照，后续不再跟随计划变化。

## 7. 功能范围

### 7.1 布置页面

布置页面保留创建作业的单一职责，不展示进行中的作业计划。

页面字段顺序以已确认原型为准：

1. 选择科目；
2. 作业时间计划；
3. 作业标题；
4. 听写配置；
5. 作业要求；
6. 预计时长（若现有正式页面保留该字段）；
7. 发布作业。

顶部不展示左侧菜单按钮。

### 7.2 作业时间计划

使用下拉框提供以下选项：

| 选项 | 规则 |
| --- | --- |
| 今日作业 | 默认值；直接创建当天的一份作业，不创建作业计划 |
| 最近一周 | 从今天开始连续 7 个自然日，包含今天 |
| 最近一个月 | 从今天开始连续 30 个自然日，包含今天 |
| 自定义范围 | 家长自行选择开始日期和结束日期，起止日期均包含在计划内 |

#### 自定义日期校验

- 开始日期和结束日期均必填；
- 创建计划时，开始日期不得早于今天；
- 结束日期不得早于开始日期；
- 日期采用家庭所在地/系统业务时区对应的自然日判断；
- 日期非法时不得发布，并在字段附近显示明确原因。

选择非自定义预设时，不展示自定义日期字段，但应展示计算后的日期范围摘要。

### 7.3 听写配置

- “开启听写”默认关闭；
- 关闭时只显示听写标题和开关；
- 关闭时不展示听写输入框、已添加词条或说明文字；
- 开启后展示词条输入、添加操作、已添加词条和说明；
- 开启听写后，至少添加一个非空词条才能发布或保存；
- 重复词条不得重复添加；
- 家长可以移除已添加词条；
- 关闭听写后，发布或保存的数据不包含听写配置。

### 7.4 创建行为

#### 今日作业

选择“今日作业”并发布时：

- 直接创建日期为今天的独立作业；
- 不创建仅持续一天的计划；
- 成功提示为“今日作业已发布”；
- 返回或进入家长作业页面后可看到该作业。

#### 周期计划

选择其他时间范围并发布时：

- 创建一条作业计划；
- 计划保存家长填写的完整作业模板；
- 计划当天有效时，应在同一业务流程中确保当天作业可生成；
- 成功提示为“作业计划已创建”；
- 家长可在作业页面底部看到新计划。

## 8. 每日作业生成规则

### 8.1 触发时机

学生或家长打开“作业”页面时，服务端检查该家庭所有当前有效或存在历史遗漏的计划，并补齐作业。

前端不得自行复制作业数据作为最终事实；生成逻辑应由服务端统一执行。

### 8.2 补生成范围

对于每个计划，系统检查：

- 从计划开始日期开始；
- 到 `min(计划结束日期, 今天)` 为止；
- 为范围中所有尚未生成实例的日期各生成一份作业。

因此，如果学生和家长连续多日未打开应用，再次打开时需要补生成所有遗漏日期，而不只是当天作业。

### 8.3 幂等约束

同一家庭、同一作业计划、同一目标日期最多存在一份生成实例。

必须通过数据库唯一约束或具备等效并发安全能力的机制保证幂等，不能只依赖前端防重复或应用层先查询后创建。

以下情况均不得产生重复作业：

- 学生和家长同时打开作业页面；
- 用户连续刷新页面；
- 请求超时后前端重试；
- 多个服务进程并发执行补生成；
- 生成部分成功后再次重试。

### 8.4 实例快照

生成实例复制计划当时的以下数据：

- 家庭；
- 作业类型；
- 科目；
- 标题；
- 作业要求；
- 预计时长；
- 目标日期；
- 听写开关及听写词条；
- 计划来源标识。

实例生成后，其内容不再自动跟随计划更新。

### 8.5 生成顺序和部分失败

- 遗漏日期应按日期从早到晚生成；
- 一次请求中出现部分失败时，已成功实例不得回滚成重复风险；
- 下次打开页面时继续补齐仍缺失的日期；
- 生成失败不得阻塞已有作业列表展示；
- 页面应提示“部分计划作业生成失败，请稍后重试”或等义提示；
- 不得向用户展示一份尚未持久化成功的虚假作业。

## 9. 家长作业页面

### 9.1 页面层级

家长“作业”页面保持当前页面样式和已有功能，顺序为：

1. 今日作业概览；
2. 家庭码等现有页面区域；
3. 今日待完成作业；
4. 已完成作业（如有）；
5. 页面底部的“进行中的作业计划”。

活动计划不出现在“布置”页面。

### 9.2 计划展示范围

“进行中的作业计划”只展示：

- 未被删除；并且
- 结束日期不早于今天的计划。

过期计划不在该区域展示。本期不提供过期计划历史入口。

### 9.3 计划排序

默认按以下顺序排序：

1. 已开始的计划优先；
2. 计划开始日期由近到远；
3. 开始日期相同时，最近更新的计划优先。

### 9.4 计划卡片

计划卡片应与当前“今日作业”页面的视觉体系一致，但必须明确它是计划而不是可提交作业。

每张卡片展示：

- 科目图标；
- 计划标题；
- 计划状态：进行中或即将开始；
- 听写功能标签（仅开启时展示）；
- “每天 1 份”；
- 起止日期；
- 剩余天数或距离开始天数；
- 已生成数量/计划总数量；
- 生成进度条；
- 今日是否已生成；
- 科目；
- 听写词条数量（如适用）；
- 预计时长（如已填写）；
- 最多两行的作业要求摘要；
- “编辑计划”操作；
- 低强调的“删除”操作。

计划卡不得展示实现语言，例如“打开页面时自动补齐遗漏日期”。

### 9.5 当前页面样式约束

原型新增内容应复用当前家长作业页面的设计语言：

- 今日概览沿用当前非对称圆角、薄荷绿背景、进度条和排版；
- 今日作业卡的状态标签作为标题行最后一个弹性子项展示，不绝对定位；
- 底部导航复用当前悬浮胶囊结构、图标圆形容器、激活态和安全距离；
- 不用新的整宽贴底导航替换现有导航；
- 计划卡片颜色根据科目复用现有语文、数学、英语等主题色。

## 10. 编辑作业计划

### 10.1 入口和页面

家长点击计划卡片中的“编辑计划”，进入独立的全屏“编辑作业计划”页面，而不是使用只包含少量字段的弹窗。

编辑页面不展示底部主导航，顶部提供返回按钮和居中标题。

### 10.2 可编辑字段

编辑页面回填并允许修改创建计划时的全部业务字段：

- 作业时间范围；
- 结束日期；
- 科目；
- 作业标题；
- 听写开关；
- 听写词条；
- 作业要求；
- 预计时长。

若计划已经开始：

- 原开始日期只读；
- 家长可修改结束日期，但结束日期不得早于今天；
- 家长可缩短或延长尚未生成的日期范围；
- 已生成日期和对应实例不受影响。

若计划尚未开始，允许修改开始日期和结束日期，并应用创建计划时的日期校验。

### 10.3 生效范围提示

编辑页顶部必须展示：

> 修改仅影响之后尚未生成的作业；已经生成的作业不会改变。

保存按钮附近再次展示等义说明。

### 10.4 保存

- 主操作为“保存修改”；
- 保存中禁用重复提交，并显示“保存中…”；
- 校验失败时在字段附近显示错误，并定位到第一个错误字段；
- 保存成功后返回家长作业页面；
- 刷新对应计划卡片；
- 显示“计划修改已保存”；
- 服务端更新计划时不得更新任何已生成实例。

### 10.5 放弃未保存修改

如果家长修改字段后返回：

- 显示“放弃修改？”确认；
- 说明“尚未保存的修改将会丢失”；
- 提供“继续编辑”和“放弃修改”；
- 未产生修改时可直接返回。

## 11. 删除作业计划

家长可从计划卡片或编辑页面发起删除。

删除前必须二次确认：

- 标题：“删除这个计划？”；
- 说明：“删除后将停止生成后续作业，已经生成的作业仍会保留。”；
- 操作：“取消”和“确认删除”。

确认后：

- 计划被软删除或进入等效不可生成状态；
- 之后不再生成新作业；
- 已生成作业全部保留；
- 已生成作业仍可开始、完成、提交和批改；
- 计划从活动计划区域移除；
- 显示“计划已删除，已有作业不受影响”。

## 12. 状态规则

| 状态 | 判定 | 页面展示 |
| --- | --- | --- |
| 即将开始 | 今天早于开始日期，且计划未删除 | 活动计划区域，显示距离开始天数 |
| 进行中 | 开始日期 ≤ 今天 ≤ 结束日期，且计划未删除 | 活动计划区域，显示剩余天数和生成进度 |
| 已过期 | 今天晚于结束日期 | 不在活动计划区域展示，不再生成新作业 |
| 已删除 | 家长确认删除 | 不展示，不再生成新作业 |

## 13. 权限与数据隔离

- 只有已绑定家庭的家长可创建作业计划；
- 只有同一家庭的家长可查看、编辑和删除计划；
- 学生不能查看计划管理卡片或调用计划管理接口；
- 学生可以查看和完成计划生成的独立作业；
- 所有计划和作业访问必须按 `family_id` 隔离；
- 跨家庭访问统一按资源不存在处理，返回 404；
- 服务端不得信任客户端传入的家庭 ID；
- 编辑和删除接口必须再次校验家长角色及家庭归属。

## 14. 数据要求

### 14.1 作业计划最小字段

- 唯一 ID；
- 家庭 ID；
- 创建人 ID；
- 作业类型；
- 科目；
- 标题；
- 作业要求；
- 预计时长；
- 开始日期；
- 结束日期；
- 是否开启听写；
- 听写词条集合；
- 删除状态；
- 创建时间；
- 更新时间。

### 14.2 作业实例来源字段

计划生成的作业需要记录：

- 来源计划 ID；
- 计划目标日期。

来源计划 ID 在计划软删除后仍应可用于追踪来源；不得因计划删除破坏实例读取。

### 14.3 唯一性

计划生成作业必须具备等效于以下语义的唯一约束：

```text
(source_plan_id, date) UNIQUE
```

直接创建的今日作业不受该约束影响，因为其 `source_plan_id` 为空。

## 15. API 行为要求

具体路径由后续技术设计决定，但产品能力至少包括：

1. 创建计划；
2. 获取当前家庭活动计划列表；
3. 获取单个计划详情；
4. 完整更新计划；
5. 删除计划；
6. 在加载作业列表时触发或组合执行遗漏实例补生成；
7. 返回补生成结果或部分失败信息。

所有写接口应提供明确的 400、401、403/404 和校验错误响应。跨家庭资源使用 404。

## 16. 非功能要求

### 16.1 一致性

- 补生成必须并发安全；
- 页面列表中的生成数量应来自持久化数据；
- 编辑和删除计划不得改变已生成实例；
- 删除与并发生成发生竞争时，服务端必须保证删除生效后不会继续产生新实例。

### 16.2 性能

- 打开作业页面时，补生成和列表获取不应导致重复的逐计划、逐日期前端请求；
- 服务端应批量检查活动计划和缺失日期；
- 常规家庭数据量下，生成检查应在用户可接受的页面加载时间内完成；
- 若补生成较慢，已有作业优先展示，并提供加载或重试状态。

### 16.3 可访问性和交互

- 所有按钮具备清晰标签和足够点击区域；
- 开关应表达开/关状态；
- 错误不能只依靠颜色表达；
- 弹窗支持明确取消；
- 页面滚动时底部悬浮导航不得遮挡最后一张计划卡片；
- 编辑页面保存按钮不得被软键盘或安全区遮挡。

## 17. 分析事件建议

若项目后续接入分析能力，建议记录：

- 选择的时间范围类型；
- 周期计划创建成功/失败；
- 补生成数量与失败数量；
- 计划编辑成功/失败；
- 计划删除确认/取消；
- 听写开关启用率。

本期不要求为上线阻塞条件。

## 18. 验收标准

### AC-01 默认时间范围

进入布置页面时，作业时间计划默认选择“今日作业”，自定义日期字段不可见。

### AC-02 预设日期范围

选择“最近一周”时生成包含今天在内的 7 日范围；选择“最近一个月”时生成包含今天在内的 30 日范围。

### AC-03 自定义范围

选择“自定义范围”后显示开始、结束日期；非法范围无法发布，并显示明确错误。

### AC-04 今日作业创建

选择“今日作业”发布后只创建当天作业，不创建计划。

### AC-05 周期计划创建

选择多日范围发布后创建计划，并在家长作业页面底部显示。

### AC-06 听写条件展示

听写默认关闭，关闭时输入框和说明完全不可见；开启后才显示。

### AC-07 空听写校验

开启听写但未添加词条时，发布或保存失败并提示至少添加一个词条。

### AC-08 每日生成

计划范围内每个日期可以生成一份独立作业，作业日期与计划目标日期一致。

### AC-09 遗漏补生成

连续三天无人打开应用后，第四天打开作业页面，系统补生成计划范围内截至当天所有缺失日期的作业。

### AC-10 幂等

同一计划和日期在重复刷新、请求重试及家长学生并发访问时始终最多存在一份作业。

### AC-11 编辑快照隔离

编辑计划后，已生成作业内容保持不变；之后生成的作业采用新内容。

### AC-12 删除快照隔离

删除计划后不再生成新作业；已生成作业继续存在并可完成、提交和批改。

### AC-13 活动计划位置

布置页面不展示活动计划；家长作业页面底部展示未过期、未删除的活动计划。

### AC-14 完整编辑

家长可从计划卡进入全屏编辑页面，并修改时间范围、科目、标题、听写、作业要求和预计时长。

### AC-15 权限隔离

学生不能编辑或删除计划；其他家庭的家长无法查看或操作本家庭计划。

### AC-16 失败降级

补生成失败时，已有作业仍可展示；页面提示失败并允许后续打开时重试，不产生重复实例。

### AC-17 视觉一致性

今日概览、今日作业卡状态标签和底部导航沿用当前家长作业页面组件样式；计划卡与当前科目配色一致。

## 20. 发布边界

本功能完成需同时具备：

- 数据库迁移；
- 作业计划模型及家庭隔离；
- 服务端并发安全的补生成能力；
- 计划管理 API；
- 布置页面时间范围和听写条件展示；
- 家长作业页面底部活动计划区域；
- 完整计划编辑页面；
- 删除确认和失败反馈；
- 后端自动化测试；
- 前端关键交互测试或等效验证；
- 已确认原型中的核心视觉和交互验收。

仅完成前端静态页面、仅在客户端复制作业或缺少数据库幂等约束，均不视为功能完成。

## 21. 已确认决策摘要

1. 默认时间范围为今日作业。
2. 最近一周为含今天的连续 7 天。
3. 最近一个月为含今天的连续 30 天。
4. 再次打开时补生成全部遗漏日期，不跳过历史日期。
5. 编辑计划只影响尚未生成的作业。
6. 删除计划只停止后续生成，保留全部已生成作业。
7. 听写默认关闭，关闭时完全隐藏输入与说明。
8. 活动计划位于家长作业页面底部，不在布置页面。
9. 编辑计划使用独立完整页面，可编辑全部创建字段。
10. 交互和视觉以已确认的 `prototype.html` 为准。
