# FeaturePilot 变更历史

## 2026-07-12: recurring-homework-plan

**目标：** 允许家长一次创建具有明确日期范围的作业计划，由系统按日期生成独立作业，降低每日重复布置成本并避免漏布置。生成后的作业继续沿用现有完成、提交、批改和听写流程。

**变更点：**
- 新增独立作业计划、计划听写模板以及普通作业的来源计划关系。
- 新增计划创建、活动列表、详情、完整编辑、软删除和家庭权限隔离 API。
- 新增显式、幂等的遗漏作业补生成能力，按计划隔离事务并保存作业与听写快照。
- 布置页面支持今日、最近一周、最近一个月和自定义日期范围。
- 听写默认关闭，关闭时完全隐藏输入区域和说明。
- 家长作业页面底部展示活动计划、生成进度及编辑和删除入口。
- 新增完整计划编辑页、脏状态确认、乐观并发冲突提示和重新加载流程。
- 学生和家长打开作业页面时先补生成遗漏作业，再加载具体作业。
- 增加后端、前端自动化测试、类型检查和 H5 构建验证。

**结构冲突：** None
